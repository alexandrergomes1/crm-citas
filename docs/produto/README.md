# Produto · crm-agenda (configuração do projeto)
- **O que é:** sistema de gestão para estúdios de estética (agenda, clientes, ficha de anamnese, comanda, caixa, financeiro, mensagens, marketing, fidelidade).
- **Para quem:** dona do estúdio, recepção e profissionais; uso intenso no celular.
- **Países no lançamento:** Espanha, Brasil e Portugal; idiomas pt, es, en.
- **Módulos e recursos:** um arquivo por módulo em `docs/produto/modulos/` (estado de cada recurso: planejado, decidido, construído, verificado).
- **Sistema antigo:** `docs/produto/legado/`, só leitura, nunca vale como decisão.
