# Clientes

## O que é
Cadastro das clientes do estúdio, com o histórico de cada uma.

## Para quem
dona, recepção, profissional

## Recursos
Lista candidata; o que entra na primeira versão se decide na spec do módulo.
- lista, busca, filtros, criar, editar, perfil
- histórico de atendimentos
- notas e alertas
- etiquetas e segmentos
- consentimento de marketing
- juntar duplicados
- saldo da cliente
- exportar

## Quando entra
Núcleo da primeira versão (E3·2).
