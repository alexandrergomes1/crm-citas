# Agenda

## O que é
Mostra os horários do estúdio e de cada profissional, para ver o dia e organizar os atendimentos.

## Para quem
dona, recepção, profissional

## Recursos
Lista candidata; o que entra na primeira versão se decide na spec do módulo.
- visões dia, 3 dias, semana e mês
- altura das horas
- filtros
- bloqueio de horário (único e repetido)
- lista de espera
- arrastar para remarcar
- status no cartão
- resumo do dia
- conflito de horário
- exportar e imprimir
- aviso no sininho
- ligação com Google Agenda

## Quando entra
Núcleo da primeira versão (E3·2).
